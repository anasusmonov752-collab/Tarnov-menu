# Tarnov — Menyu O'qitish Tizimi

Tarnov oilaviy restoran uchun ofitsiantlarni menyu bo'yicha o'qitish va baholash tizimi.

## Imkoniyatlar

- **Admin panel** — taom qo'shish, rasm yuklash, tahrirlash, o'chirish
- **O'rganish** — ofitsiantlar uchun interaktiv menyu
- **Test** — bilimlarni sinash (ball tizimi bilan)
- **Reyting** — ofitsiantlar natijalarini kuzatish

## Ishga tushirish (lokal)

```bash
npm install
npm start
```

Brauzerda oching: http://localhost:3000

## Render.com ga joylashtirish

1. GitHub ga yuklang
2. Render.com → New Web Service
3. GitHub repo ni tanlang
4. Build: `npm install` | Start: `npm start`
5. Deploy tugmasini bosing

## Texnologiyalar

- Node.js + Express
- Multer (rasm yuklash)
- UUID (unikal ID)
- Vanilla JS (frontend)
